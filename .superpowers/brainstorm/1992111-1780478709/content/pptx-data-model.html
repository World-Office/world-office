PPTX Data Model — wo-ooxml Extension

New types added to the existing wo-ooxml crate for PPTX roundtrip

New Model Types

PptxPresentation {
  slide_size: SlideSize,
  slides: Vec<Slide>,
  slide_layouts: Vec<SlideLayout>,
  theme: Option<Theme>
}

Slide {
  id: u32,
  name: String,
  layout_id: String,
  shapes: Vec<SlideShape>,
  notes: Option<String>
}

SlideShape {
  id: String,
  shape_type: ShapeType,
  bounds: Bounds { x, y, cx, cy },
  text_body: Option<TextBody>,
  placeholder: Option<PlaceholderInfo>
}

TextBody {
  paragraphs: Vec<DocxParagraph>,
   — reuses existing DOCX paragraph/run types!
}

Bounds { x: i64, y: i64, cx: i64, cy: i64 }
// EMU coordinates (1/914400 inch — standard OOXML)

Reuses Existing Infrastructure

Reuses

  • DocxParagraph / DocxRun (text formatting)
  • Zip archive handling
  • Content type detection
  • Relationship parsing
  • FormatRoundtrip trait

New (PPTX-specific)

  • Slide shape types (subtitle, body, pic, table, etc.)
  • Slide layout/master references
  • Placeholder info
  • Theme colors/fonts (minimal)

Question: What shape types for MVP?

1

Minimal — Text only

Shapes: body, title, subtitle, textBox. No images, tables, charts.

2

Text + Images

Adds picture shapes. Users can insert images on slides.
