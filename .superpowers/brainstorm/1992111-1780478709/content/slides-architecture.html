Slides Editor — Design Proposal

Building on wo-ooxml for native PPTX roundtrip

Architecture (OOXML-Native)

Data flow: PPTX file → wo-ooxml parser (extended) → PresentationStore (MobX) → Canvas renderer → wo-ooxml serializer (extended) → PPTX file

Follows the same pattern as wo-docx: parse OOXML ZIP into typed model, edit in memory, serialize back.

Backend: wo-ooxml PPTX Extension

Add to existing wo-ooxml crate:

  • Model types — PptxPresentation, Slide, SlideShape, Placeholder
  • PPTX parser — read ppt/slides/slide*.xml, ppt/slideLayouts/*.xml, ppt/presentation.xml
  • PPTX serializer — write slides back to OOXML ZIP

Frontend: presentationeditor-react

Already has full scaffolding. MVP adds:

  • Slide Manager — thumbnails panel (left), add/reorder/delete slides (15 days)
  • Canvas Editor — WYSIWYG slide canvas with text boxes, drag/resize (20 days)
  • Toolbar — text formatting (bold/italic/size), shape insert (5 days)
  • PPTX Roundtrip — load PPTX, edit, save as PPTX (10 days)

Total MVP Estimate

~50 days = 2.5 sprints (3-week). Resume points after each sub-sprint.
